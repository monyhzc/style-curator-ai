真维斯图像风格审核系统 - API文档

快速上手

外部系统调用只需要 External 分组下的 3 个接口：

场景 接口
单张 / 少量图片，实时拿分数 POST /api/analyze
大批量图片（≤1000 张/批） POST /api/analyze/batch 提交 → GET /api/analyze/batch/{batch_id} 轮询

其余分组（Core / Ingestion / Workflow / Maintenance / Assets）是审图网页自身使用的接口。

curl -X POST http://<服务器地址>/api/analyze \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/photo.jpg", "task": "LIFE"}'
# => {"url": "https://example.com/photo.jpg", "probability": 0.985}

认证

所有接口都需要认证，在请求头携带：

Authorization: Bearer <TOKEN>

<TOKEN> 即服务端 .env 中配置的 APP_AUTH_TOKEN，向部署管理员索取。 浏览器登录 /login 后的会话 Cookie 同样有效（网页内部调用走这种方式）。

未认证时：/api/*、/action/*、/undo_global 返回 401 {"error": "Unauthorized"}； /image/* 等页面类路由则 302 重定向到 /login。

品牌 (task)

task / brands / new_task 参数可选以下 8 个品牌：

值 说明
LIFE
OUTDOOR
Z+
MAIN
JEANS 牛仔。被判为上装的图改用 MAIN 模型打分，结果仍记在 JEANS 下
JNR 童装 - 真维斯童装
JKIDS 童装
JSPORT 童装 - 运动

分数解读

probability 为 0–1 的风格符合度，网页端按以下阈值分档（所有品牌相同）：

区间 level level_code
probability >= 0.80 非常符合 2
0.30 <= probability < 0.80 中度符合 1
probability < 0.30 不符合 0

/api/analyze 系列接口只返回 probability，分档由调用方按上表自行判断。

速率限制

按「客户端 IP + 接口」分别计数，固定 60 秒窗口，各接口上限见接口说明。 超限返回 429 {"error": "Rate limit exceeded"}，请等待后重试。

图片 URL 限制（External 接口）

  • 仅支持 http / https，图片 ≤ 10MB，需为 PIL 可解码的图片格式。
  • 下载超时：连接 3s / 读取 5s。
  • SSRF 防护：解析到内网 / 回环 / 链路本地地址的 URL 会被拒绝。 内网部署时，需由管理员把调用方图片服务器的 IP 或网段加入服务端 data/url_allowlist.conf 白名单（保存即生效，无需重启）。

Core

核心数据检索 (GET)

获取结果列表，支持筛选

对应代码: get_results()

逻辑说明:

  1. 筛选: 根据 tab (处理状态视图) 和 filter (二级状态) 过滤数据。
  2. 排序: 根据 sort 和 order 对结果进行重排。
  3. 分页: 基于内存切片返回数据。

限流: 每个 IP 每分钟 120 次。

Authorizations:
bearerAuth
query Parameters
tab
string
Default: "pending"
Enum: "pending" "processed" "trash"

处理状态视图：

  • pending: 待审核（status 为 pending / done / error）
  • processed: 已审核（approved / rejected）
  • trash: 回收站（deleted）
filter
string
Default: "all"
Enum: "all" "high" "mid" "low" "approved" "rejected" "processed" "unprocessed"

二级过滤器，可选值取决于 tab：

  • tab=pending: high (非常符合) / mid (中度符合) / low (不符合)
  • tab=processed: approved / rejected
  • tab=trash: processed (删除前已审核) / unprocessed (删除前未审核)

all 或与 tab 不匹配的值表示不过滤。

brands
required
string
Example: brands=LIFE,MAIN

品牌列表，多个用英文逗号分隔，如 LIFE,MAIN。

可选值: LIFE, OUTDOOR, Z+, MAIN, JEANS, JNR, JKIDS, JSPORT。

不传或传空时返回空列表（不是返回全部）。

sort
string
Default: "id"
Enum: "id" "score" "name"

排序字段：id (上传顺序) / score (置信度) / name (文件名)

order
string
Default: "desc"
Enum: "desc" "asc"

排序方向

page
integer
Default: 0

分页页码 (从 0 开始)

limit
integer
Default: 50

每页图片数量

Ingestion

数据录入与 AI 初始化 (POST)

上传图片 (Multipart)

对应代码: upload()

功能:

  1. 保存文件到 uploads 目录。
  2. 生成缩略图。
  3. 写入内存数据库 RESULTS。
  4. 推入 task_queue 触发 AI 计算。

异步: 返回 ok 只代表已入队，AI 结果需稍后通过 GET /api/results 查询（首次推理需加载模型，可能较慢）。

注意:

  • task 不在可选值内时**静默回退为 LIFE**，不报错。
  • 缺少 files 字段时返回 HTTP 200 + {"status": "error"}。
  • 单次请求体上限 1GB，超出返回 413。

Workflow

审核流程与状态管理 (POST)

单样本操作 (Form)

对应代码: operate(item_id) -> execute_action

注意: 使用 x-www-form-urlencoded 传输 action。

动作含义:

  • approve / reject: 审核通过 / 拒绝
  • delete: 移入回收站（记录删除前状态）
  • withdraw: 撤回审核，回到待审核
  • restore: 从回收站恢复到删除前状态
  • permanent_delete: 彻底删除（仅对回收站内的样本生效，删除文件且不可撤销）

只要样本存在就返回 ok，即使动作未实际生效（如对已通过的样本再次 approve、未知动作）。

限流: 每个 IP 每分钟 60 次。

External

外部调用接口 (POST)

单张图片风格分析 (同步)

对应代码: analyze()

功能:

  1. 通过 URL 下载图片 (限制 10MB)。
  2. 使用 SigLIP 提取特征，经 MLP 分类器计算置信度。
  3. 支持动态批处理 (APIBatcher)，高并发下自动合并请求。

安全机制:

  • 流式下载，分块校验大小 (防止内存溢出)。
  • HTTP 超时：连接 3s / 读取 5s。
  • SSRF 防护：内网 / 回环地址返回 URL not allowed，内网部署需加白名单（见文档开头）。

适用场景: 少量图片的实时分析。大批量请求请使用 /api/analyze/batch。

限流: 每个 IP 每分钟 20 次。

bearerAuth
Request Body schema: application/json
required

string <uri>

提交批量分析任务 (异步)

对应代码: analyze_batch()

功能:

  1. 接收一组图片 URL（最多 1000 条）。
  2. 立即返回 batch_id，后台队列异步处理。
  3. 通过 GET /api/analyze/batch/{batch_id} 轮询进度与结果。

处理机制:

  • 后台 4 线程并发下载 + 推理。
  • 提交时不校验单条 URL；下载失败、被安全策略拒绝等都在结果里逐条标记为 failed，不影响其余。
  • 结果保存在服务端内存中，保留 24 小时后自动清理；服务重启后结果丢失。

限流: 每个 IP 每分钟 5 次。

查询批量任务进度与结果

对应代码: analyze_batch_status()

轮询建议:

  • 处理中 (status=processing): 每 2-5 秒轮询一次（本接口限流 60 次/分钟）。
  • 已完成 (status=completed): 读取 results 数组获取逐条结果，顺序与提交的 urls 一致。
  • 结果保留 24 小时，过期或服务重启后返回 404。

单条 error 可能的值:

  • Failed to download image: 下载失败 / 超时 / 对方返回非 2xx
  • URL blocked by security policy: 内网地址等被 SSRF 防护拒绝
  • Image exceeds 10MB limit: 图片超过 10MB
  • 其他: 图片无法解码或推理异常的原始报错

限流: 每个 IP 每分钟 60 次。
